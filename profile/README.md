# Dornglut

Dornglut develops the **Runen ecosystem**: modular Rust frameworks, an integration platform, a programming language, and engineering tools.

## Platform & language

- [**Runenwerk**](https://github.com/dornglut/runenwerk) — integration platform and reference engine for applications, editors, simulations, and rendering.
- [**Runen**](https://github.com/dornglut/runen) — programming language under development.

## Frameworks

- [**RunenECS**](https://github.com/dornglut/runen-ecs) — entity-component-system framework.
- [**RunenGPU**](https://github.com/dornglut/runen-gpu) — backend-neutral GPU execution.
- [**RunenGraph**](https://github.com/dornglut/runen-graph) — graphs and relationships.
- [**RunenNet**](https://github.com/dornglut/runen-net) — realtime multiplayer networking.
- [**RunenOnline**](https://github.com/dornglut/runen-online) — online-game control-plane semantics.
- [**RunenSDF**](https://github.com/dornglut/runen-sdf) — signed-field mathematics and queries.
- [**RunenShader**](https://github.com/dornglut/runen-shader) — shader source and compilation.
- [**RunenSpatial**](https://github.com/dornglut/runen-spatial) — large-world spatial mechanics, demand planning, and availability control.
- [**RunenUI**](https://github.com/dornglut/runen-ui) — host- and renderer-neutral UI.
- **RunenRender** — planned standalone rendering framework built on RunenGPU and RunenShader.

## Applications

- [**Werkstatt**](https://github.com/dornglut/werkstatt) — human-first software engineering workbench.
- [**Runen Lab**](https://github.com/dornglut/runen-lab) — workspace for downstream experimental and showcase applications.

## Engineering

- [**Engineering**](https://github.com/dornglut/engineering) — architecture, standards, ADRs, and governance.
- [**GitHub Workflows**](https://github.com/dornglut/github-workflows) — reusable CI orchestration.
- [**Organization defaults**](https://github.com/dornglut/.github) — shared GitHub defaults and templates.

## Design

Dornglut keeps reusable systems independently owned and composable. Frameworks define their own semantics; Runenwerk integrates them without duplicating their authority.
