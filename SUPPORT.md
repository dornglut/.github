# Support

Use the affected repository's issue tracker for reproducible defects, documentation problems, and bounded feature requests.

Before opening an issue:

- search existing issues and pull requests;
- identify the repository, revision, platform, and relevant configuration;
- provide the smallest useful reproduction and observed evidence;
- distinguish a usage question from a defect or architecture proposal.

Security reports must follow [SECURITY.md](SECURITY.md). The organization does not currently provide guaranteed response times or private product support.
